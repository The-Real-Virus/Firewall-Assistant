# Maintenance plan

After actual release, recommend monthly dependency/Windows/model-policy review and relevant compatibility retests. No automation is created. Updates use a separately verified complete folder, preserving cases. Remove saved credentials deliberately; uninstall by program-folder removal plus separate operator data review. Rollback restores application files only, never external policy changes.

This is a preparation record. It will be replaced with exercised instructions/results during its implementation package; it does not claim working software.
