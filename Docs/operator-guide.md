# Operator workflow for the local V1.0 candidate

Extract the complete portable folder and keep FirewallAssistant.exe, wfdiag.exe, runtime
resources and notices together. Use a normal account and leave AI disabled. The current
evaluation has local build/CLI/source checks; clean-target GUI/native collection acceptance
is unfinished. installation.md and known-limitations.md identify that boundary.

Open example shows invented engine results without inspecting the computer. For an approved
capture, use Open case folder or Cases. A known-file directory is required; report HTML,
arbitrary ZIP and raw EVTX are not case inputs. Reopening validates the evidence again.
Start investigation checks access, collects and analyzes in sequence. General review needs no
technical connection fields; focused intent is optional. Reproduce the real failure first.
Default lookback10 minutes can be changed to1–60 in folded manual controls. No target is launched
or probed. Missing protected-event access offers Request Windows permission, limited collection
or Cancel. Only a deliberate user choice launches the verified read-only sibling collector
through Windows consent. GUI/AI remain normal; no auditing/firewall setting changes. Actual
consent collection was observed on the development host; broader native validation is unfinished.

Read completeness, category, grade and relevance separately. Findings/Evidence show bounded
500-row pages with page-only search. Reveal local details deliberately; changing page hides
them again. Candidate rules are not confirmed causes. Intent edits require reanalysis before
proposal export. Proposals are review JSON with executable false; refusals preserve uncertainty.

Export defaults to share mode. Review the redacted derivative before transferring it through
an approved channel. Local full mode requires disclosure confirmation and a verified private
parent. Both formats export the complete original analysis, regardless of the displayed page.
Choose a new `.html` or `.json` filename. Output limits are128MiB JSON/256MiB HTML; input
limits remain128MiB/source and256MiB/case. A cap or cancellation refuses final publication
and removes staging. Existing files remain intact. Open a validated generated HTML report
only deliberately; no browser operation is required to create it. Browser QA is still blocked.

Compare accepts only validated analysis files, rejecting raw network/rules/manifest JSON early.
It labels Before/After and preserves each capture's uncertainty. Fewer recorded events
does not establish a repair. History is off by default; clearing its index never deletes cases.
Cancel requested means wait for actual cleanup. Closing during a job waits for the owned work
to stop; no hidden tray worker is provided. AI remains separate, optional and default off.

Shared source/worker workflows exercise analysis/report/comparison and full-case paging export
with explicit privacy doubles; these do not establish Windows ACL acceptance. See cli.md for
exercised synthetic CLI commands, privacy.md for handling, and handbook-verification.md for
the final tested handbook/publication work still required. No production readiness is claimed.
