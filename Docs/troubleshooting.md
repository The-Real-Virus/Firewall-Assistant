# Troubleshooting the development evaluation

Record operation, version, Windows build, time and safe error code. Preserve originals and use
new outputs for retries. Failed/incomplete is not passed. Never post private cases, paths, raw
stderr or keys publicly. The private support channel is still an owner decision; see SECURITY.md.

| Symptom | Safe action | Acceptance still needed |
|---|---|---|
| GUI will not start | Use the replacement package in BUILD-RESULT.md and extract its whole folder; retain any fixed support code. Older0.1.0 contains an incompatible ambient ICU DLL. Never download/replace individual DLLs | Exact Windows10 replacement retest and clean-machine/security-product observations |
| GUI_IMPORT_FAILED or GUI_STARTUP_FAILED | Preserve the code and complete package identity for the maintainer; exception paths and case/key text are deliberately omitted | Native loader failures before Python can require OS evidence |
| Engine missing, modified or different version | Restore the complete matching trusted folder; no PATH/case-folder engine substitution | Source refusals pass; frozen GUI repair journey pending |
| Private app/work location unavailable | Resolve ownership/permissions through IT and use an approved protected local parent | Native ACL/inheritance/access-denial tests |
| Second instance refused | Use/close the existing instance; never delete an active lock | Native standard/elevated instance tests |
| Input invalid, missing or hash changed | Keep original; inspect supported schema/required files, without editing evidence to make hashes agree | Hostile source tests pass; native capture acceptance pending |
| Output exists | Choose a new filename/directory in an existing allowed parent | Source atomic/no-overwrite checks pass |
| Access denied or unsupported source | Preserve its distinct state; request approved capture from the responsible administrator | Exact A01/target evidence |
| Script policy blocks collection/helper | Stop and follow approved signing/development procedure; no execution-policy bypass | Prior5.1 refusal remains blocked |
| Incomplete, capped, timeout or cancelled | Preserve staging; obtain missing authorized evidence in a new run | Target cancellation/cleanup acceptance |
| No relevant event | Review flow/window/completeness/auditing/identity; absence is not a healthy-host verdict | Native ground truth |
| Proposal withheld | Read refusals, uncertainty and policy owner; independently confirm intent then reanalyze | Never broaden peers/profiles or override managed/explicit blocks |
| Search has no rows | Search/filter covers the loaded500-row page; hidden fields excluded until Reveal | Review pages/full report; no global absence inference |
| Share export refused | Review disclosure/unsupported fields; never relabel full data as safe | Canary source checks exist; browser/network review pending |
| Worker/protocol/output failure | Retain current case/intent; inspect complete program/version and safe code, then choose a fresh job | Source process checks pass; native/frozen journeys pending |
| AI unavailable/offline/no key | Continue with AI disabled; core needs no key | Live/configured packaged journey pending |
| AI TLS/redirect/schema/rate/quota/billing error | Keep TLS/host controls; no automatic provider fallback or retry; inspect account privately | Exact A07 before live retry |
| AI timeout/cancel | Ignore late response; provider processing/charges may still have occurred | No automatic retry or zero-charge promise |

Stable CLI result codes:0 completed operation;2 invalid/refused input/output;3 unsupported or
unavailable;4 access denied/private output unavailable;5 incomplete/cancelled;6 internal/worker
validation failure. Code0 means completed operation, not safe Windows or repaired connection.
Source failures remain in the case statuses.

Technical stderr is memory-only, capped1MiB for the current/last job. Settings / Clear diagnostic
log buffer works while idle and removes no cases/exports/requests/history. No secure-memory-
erasure promise. Do not bypass endpoint protection/app approval to inspect a report; the prior
browser visual check remains blocked.
