# Reporting a vulnerability

Use GitHub's private vulnerability reporting option if it is available for this repository. Otherwise, contact a maintainer privately to arrange a reporting channel. Include the affected version, steps to reproduce with synthetic data, and the observed impact.

Keep real cases, Security logs, private reports, API keys, and credentials out of public issues. The portable V1.0 build is unsigned.
