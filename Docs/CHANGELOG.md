# Changelog

## V1.0 release candidate

- Added a shared Windows Firewall diagnostic engine, desktop GUI, and administrator CLI.
- Added read-only evidence collection, permission-aware investigation, case comparison, and local report exports.
- Added an optional AI Assistant with provider setup, chat, and supported application actions. Diagnostics run offline and AI starts disabled.
- Improved work-folder selection, report filenames, and feedback during investigation and comparison.
- Added the user handbook, build instructions, synthetic examples, and tests.

The desktop displays `V1.0`. The internal package and engine version is `1.0.0rc1`. [Validation record](evidence/v1-handoff-20261109.md)
